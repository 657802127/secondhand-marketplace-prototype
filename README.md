# 闲置集市 · 二手交易小程序原型

闲鱼风格的二手交易平台高保真原型，按 **微信小程序 750rpx 设计稿** 还原，纯静态、零依赖、离线可用。

---

## 快速预览

双击打开 `index.html` 即可（无需服务器、无需安装依赖）。

- 外层是 iPhone 尺寸手机壳，内层完整模拟小程序：状态栏、自定义导航栏、页面栈右滑转场、底部 tabBar、安全区
- 左侧「页面导航」可直接跳到任意页面，方便评审
- 窗口变矮时手机自动等比缩放，保证完整可见

> 建议用 Chrome / Edge 打开。

## 完整交易链路（可点通）

```
首页 → 商品详情 → 立即购买 → 确认订单 → 微信支付
   → 支付成功 → 我的订单 → 订单详情
   → 🛠 模拟卖家发货 → 确认收货 → 评价 → 已完成
```

订单详情页的「模拟卖家发货」是**演示辅助按钮**，用来跳过真实发货等待，方便一次走完全流程。

---

## 交互细节

- **页面栈**：push 右滑入、pop 右滑出，返回时自动恢复滚动位置
- **tabBar**：首页 / 消息 / 发布（凸起键）/ 我的，进入二级页自动隐藏
- **状态持久化**：收藏、订单、发布、会话、登录态存 `localStorage`，刷新不丢
- **反馈**：Toast、底部弹层（ActionSheet）、空状态、支付成功动画
- **数据重置**：我的 → 设置 → 重置演示数据

## 改成真实小程序

1. **结构**：每个 `App.page(name, {...})` 对应一个 `pages/xxx/xxx.wxml`；`render()` 返回的 HTML 结构可直接转 WXML（`class` 保持不变，标签 `div` → `view`，`img` → `image`）
2. **样式**：`styles.css` 中的 px 数值 ×2 即为 rpx；CSS 变量换成 `app.wxss` 里的同名变量
3. **数据**：把 `data.js` 里的 mock 换成 `wx.request`，`App.save()` 换成后端接口
4. **路由**：`App.router.go()` → `wx.navigateTo`，`switchTab()` → `wx.switchTab`，`back()` → `wx.navigateBack`
5. **登录**：`do-login` 换成 `wx.login` + `wx.getUserProfile`
6. **支付**：`do-pay` 换成 `wx.requestPayment`
